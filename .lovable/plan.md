

# 🏋️ Limassol Fitness — Мобильное приложение (PWA)

Установочное веб-приложение для персонального тренера Illarion Ientin. Клиенты смогут бронировать тренировки, просматривать цены и информацию, а тренер получает уведомления о новых записях.

## Дизайн
Тёмная тема в современно стиле трендов и цветов модных для 2026г. Мобильный интерфейс, нижняя навигация, современный фитнес-стиль. Двуязычный — английский + русский с переключателем.

## Фаза 2: Бронирование тренировок (требует бэкенд — Lovable Cloud)

### 7. Система бронирования
- Календарь с доступными слотами для записи
- Выбор типа тренировки
- Форма с именем, телефоном и заметками клиента
- Подтверждение бронирования на экране

### 8. Уведомления тренеру на выбор одна из функций и для клиента выбор нужен для получения уведомлений. Чтобы не было спама по всем фронтам. Пусть сам решает куда ему надо подтверждение. 
Подтверждение отправленное также должно включать функцию отмены бронирования с уведомлением двух сторон и редактированием календаря, при условии использования календаря. 
- **Email**: письмо о новой записи через Resend
- **Telegram бот**: мгновенное уведомление в Telegram при новой записи
- **Google Calendar**: автоматическое добавление тренировки в Google Calendar тренера
