# Anatomical body source

Base mesh and male/muscle targets from MakeHuman Community, released as CC0 1.0 Universal.

- Source: https://github.com/makehumancommunity/makehuman
- License: https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.ASSETS.md
- Base: `makehuman/data/3dobjs/base.obj`
- Targets: `caucasian-male-young.target`, `universal-male-young-maxmuscle-averageweight.target`

Only graphical assets are used, not MakeHuman program code. The body-only mesh has been triangulated and normalized for this illustrative measurement viewer.
